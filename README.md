# 🏋️ Fitness Tracker - Full Stack Web Application

## 🚀 Overview

**Fitness Tracker** is a full-stack web application designed to help users monitor and improve their fitness journey. It enables users to track daily workouts, maintain healthy eating habits, record body measurements, and monitor overall fitness progress through an intuitive and responsive interface.

The application is built using **React.js** for the frontend and **Java, Spring Boot, MySQL, and REST APIs** for the backend, providing a seamless and efficient user experience.
